# goen-base · Goen 的秘密基地

每天打开的个人起始页，笔记涂鸦风。

- **首页**：撕页日历（进场会翻页）、激励小插画、每日一句（英 / 中 / 日）、今年进度
- **小贴纸 + 右侧抽屉**：雅思学习、日语学习、今日小目标、后端学习笔记的入口；手机上从右边缘往左滑拉出抽屉
- **后端图解**（`#/backend`）：Java · Spring · 数据库 · 网络的手绘图解

## 技术

- Vue 3（CDN 全局版）+ Vue Router 4（hash 模式）
- 单文件 `index.html`，不需要构建，直接打开或丢到任何静态托管上就能用
- 适配手机、iPad 竖屏 / 横屏、电脑；跟随系统深色模式

## 本地预览

```bash
# 任选一种，在项目目录里起一个静态服务器
python3 -m http.server 5500
# 然后打开 http://localhost:5500
```

## 部署

Vercel 导入本仓库即可（Framework 选 Other，不需要构建命令）。
